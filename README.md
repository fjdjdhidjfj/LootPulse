# LootPulse

> **Автономный трекер сундуков Fortnite с синхронизацией сквада, игровым HUD-оверлеем и детальной статистикой.**

LootPulse отслеживает добытые сундуки в реальном времени, анализируя локальные файлы реплеев Fortnite, транслирует результаты тиммейтам в комнате и отображает компактную оверлей-таблицу прямо поверх игры.

---

## Возможности

- **Анализ реплеев в реальном времени**: автоматическое обнаружение свежих реплеев Fortnite, учёт открытых и сломанных сундуков в радиусе до 100 метров от игрока, непрерывная интерполяция координат.
- **Вкладка «Статистика»**:
  - График добытых сундуков за последние 7 дней с числовыми показателями над каждым столбцом.
  - Интерактивная детализация по клику на любой день: сундуков в час (CPH), чистое время в матчах, среднее число сундуков за катку, общее количество сундуков и каток, таблица сыгранных матчей с CPM.
- **Игровой HUD-оверлей**:
  - Компактная таблица (`Player`, `Last`, `All`, `Session`) поверх игры в режиме «Окно без рамки».
  - Раздельная настройка прозрачности фона и текста.
  - Закрепление (клик сквозь окно): `Ctrl + Shift + L`.
  - Скрытие/показ по горячей клавише: `Ctrl + Shift + O`.
  - **Режим «Только в игре»**: оверлей автоматически скрывается, когда Fortnite свёрнут, и не нагружает систему.
- **Синхронизация пати (Squad Sync)**:
  - Подключение к общей комнате по кодовому слову.
  - Передача прогресса тиммейтам в реальном времени через защищённое реле в оперативной памяти (без сохранения данных чужих ПК).
- **Автообновление из GitHub**:
  - Фоновая проверка обновлений при запуске и ручная кнопка в Настройках.
  - Бесшовная замена исполняемого файла в один клик напрямую из GitHub Releases.

## Архитектура и стек

- **Язык и платформа**: C# 10 / .NET 10 (Windows x64).
- **GUI**: гибридный интерфейс на Microsoft WebView2 (HTML5, CSS Variables, нативный JS) с кастомным drag-тайтлбаром и zero-latency REST/Event bridge.
- **Оверлей**: прямой Win32 API (`CreateWindowEx`, `WS_EX_LAYERED`, `UpdateLayeredWindow`, GDI+ double-buffering) с независимой оконной процедурой и нулевой задержкой отклика.
- **Парсер реплеев**: интеграция с `FortniteReplayReader`, `Unreal.Core` и `OozSharp` (декомпрессия Kraken/Oodle).
- **Тесты**: xUnit тестовый набор (19 unit-тестов), проверяющий парсер, синхронизацию пати, оверлей и механизм обновлений.

## Сборка и запуск

### Требования
- Windows 10/11 x64
- [.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0)

### Быстрая сборка
Запустите скрипт сборки в корне проекта:
```cmd
build.bat
```
Скрипт создаст единый автономный файл `dist\LootPulse.exe` (включая все нативные зависимости и рантайм).

### Ручная сборка через CLI
```bash
dotnet publish src/LootPulse/LootPulse.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -p:EnableCompressionInSingleFile=true -p:DebugType=none -o dist
```

### Запуск тестов
```bash
dotnet test tests/LootPulse.Tests/LootPulse.Tests.csproj
```
